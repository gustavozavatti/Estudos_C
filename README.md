# 📚 Estudos em C

Repositório criado para registrar minha evolução nos estudos da linguagem **C** durante a graduação em Ciência da Computação.

Aqui estão reunidos exercícios, práticas, algoritmos, estruturas de dados e pequenos projetos desenvolvidos ao longo dos meus estudos.

## 📋 Sobre o projeto

Este repositório funciona como um registro da minha evolução na linguagem **C**, começando pelos conceitos fundamentais de programação e avançando gradualmente para conteúdos mais complexos.

Os conteúdos estão separados em pastas e organizados em uma sequência de estudos, facilitando o acompanhamento da evolução dos conceitos aprendidos e praticados.

## 📚 Conteúdos

| Pasta | Conteúdo |
|---|---|
| `01 - LogicaBasica` | Lógica de programação e exercícios iniciais |
| `02 - EstruturasBasicas` | Estruturas condicionais, repetição, vetores e matrizes |
| `03 - Funções` | Criação e utilização de funções |
| `04 - Recursividade` | Funções recursivas e resolução de problemas com recursão |
| `05 - Structs` | Estruturas e organização de dados |
| `06 - Ponteiros` | Ponteiros, endereços e manipulação de memória |
| `07 - Alocação` | Alocação dinâmica de memória |
| `08 - Busca` | Algoritmos de busca e localização de dados |
| `09 - Ordenação` | Algoritmos de ordenação |
| `10 - EstruturaDados` | Estruturas de dados como listas, filas e pilhas |
| `11 - Bibliotecas` | Utilização e prática com bibliotecas da linguagem C |
| `12 - PequenosProjetos` | Pequenos projetos desenvolvidos para aplicar os conteúdos estudados |

## 🔎 Algoritmos

Durante os estudos também são praticados diferentes algoritmos para trabalhar com dados.

Entre eles estão:

- Busca sequencial
- Busca binária
- Bubble Sort
- Insertion Sort
- Selection Sort
- Quick Sort

Esses exercícios ajudam a compreender diferentes formas de pesquisar e organizar dados, além de desenvolver o raciocínio lógico e a análise dos algoritmos.

## 🗂️ Estruturas de dados

O repositório também possui estudos relacionados à implementação e manipulação de estruturas de dados.

Entre os conteúdos estudados estão:

- Listas
- Listas duplamente encadeadas
- Pilhas
- Filas

Esses conceitos permitem aprofundar os conhecimentos sobre organização, armazenamento e manipulação de dados.

## 🎮 Pequenos projetos

Além dos exercícios individuais, o repositório possui uma área destinada a **pequenos projetos**, desenvolvidos para aplicar na prática diferentes conceitos estudados durante a aprendizagem da linguagem C.

Esses projetos permitem combinar diferentes conteúdos, como funções, `struct`, ponteiros, estruturas de repetição, estruturas de dados e gerenciamento de memória.

## 🎯 Objetivo

O principal objetivo deste repositório é acompanhar minha evolução na linguagem **C** e colocar em prática os conteúdos estudados durante a graduação.

Através dos exercícios e projetos, busco desenvolver conhecimentos em:

- Programação
- Lógica
- Algoritmos
- Estruturas de dados
- Gerenciamento de memória
- Resolução de problemas

## 🚀 Evolução

Os conteúdos estão organizados de forma progressiva, começando pelos conceitos fundamentais e avançando para algoritmos, gerenciamento de memória, estruturas de dados e projetos.

A organização do repositório representa meu processo de aprendizado e permite acompanhar a evolução dos conceitos mais básicos até conteúdos mais complexos.

Este repositório está em constante atualização conforme novos conteúdos são estudados e novos exercícios e projetos são desenvolvidos.
